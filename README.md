# SmartWatch Product Landing Page

## About the Webpage

This project is a responsive product landing page for a SmartWatch. It showcases the product's features, pricing, customer reviews, and includes an order form where customers can enter their details to place an order.

## AI Tool Used

ChatGPT was used as the AI tool for this project.

## How AI Helped

AI helped with generating and improving the HTML and CSS structure of the webpage. It provided suggestions for the page layout, responsive design, styling, hover animations, customer review cards, navigation, and order form. AI was also used to troubleshoot issues and improve the overall user experience and appearance of the landing page.
